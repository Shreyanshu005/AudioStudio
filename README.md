
# Audio Replay Studio

An advanced web application for audio editing with listener engagement insights.

## Project info

**URL**: https://lovable.dev/projects/a11d5a0f-09eb-4e49-8809-ccdc336b9b3d

## Features

- 📂 Upload audio files (supports most common formats)
- 🎚️ Interactive waveform visualization
- ⏩ Adjust playback speed (0.5x to 2.0x)
- 🔊 Apply audio effects (echo and reverb)
- ✂️ Trim audio with precision
- 📊 Track and visualize which sections are replayed most often
- 💾 Export edited audio

## Technology Stack

- React with TypeScript
- Web Audio API for audio processing
- Tailwind CSS for styling
- shadcn/ui for UI components 
- recharts for data visualization

## How to Use

1. Upload an audio file using the drag & drop interface
2. Use the waveform display to visualize your audio
3. Trim unwanted sections by dragging the handles
4. Adjust playback speed and effects as needed
5. Play your audio to track which sections are replayed
6. Download the final edited audio

## Development

This project is built with:
- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

To run the project locally:

```sh
# Install dependencies
npm i

# Start the development server
npm run dev
```
